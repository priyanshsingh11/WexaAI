## Known gaps, stated plainly

1. **Repeat-run variance not characterised** — one run per configuration.
2. **No public article** — out of scope for this pass.
3. **Neo4j AuraDB Free cross-check not provisioned** — the harness supports it
   (`NEO4J_AURA_URI`); without it the cloud track has a single member, so CognoDB has no
   managed peer measured over the same link. This is the single highest-value addition.
4. **CognoDB engine performance is not isolated** — a ~390 ms WAN floor makes that
   impossible from this client. Running the harness from a us-east VM would fix it.
